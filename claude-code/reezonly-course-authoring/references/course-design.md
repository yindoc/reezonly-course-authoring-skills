# Проектирование курса

Превращать brief в outcomes, modules, lessons и evidence: observable outcome → model/example → practice artefact → assessment/feedback → transfer. Подготовить минимальную page map без пустых страниц.

Каждый lesson использует четыре semantic tabs: Theory для model/example, Testing для retrieval/feedback, Practice для contextual artefact, Materials для reusable aids. Связывать title, practice и assessment с одним outcome; использовать accessible headings, links, alt text и text alternative for media.

RichText — current bounded LMS editor HTML pass-through; Active HTML24 — отдельный unrestricted profile и выбирается по learning objective. Content plan остаётся рабочим контекстом, не audit/journal; blueprint validation выполняется только при user need и compatible current schema.
